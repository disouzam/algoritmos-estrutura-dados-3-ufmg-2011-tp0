# Sobre esse repositório

Arquivos resgatados do Trabalho Prático 0 da disciplina Algoritmos e Estruturas de Dados 3, UFMG, 2011

## BigNum

O objetivo desse trabalho foi criar um tipo abstrato de dados em C para manipular números inteiros arbitrariamente grandes e as operações matemáticas sobre esses números.

Conceitualmente os objetivos eram familiarização com a linguagem C, uso de alocação dinâmica de memória e também o uso do Make para compilação. Era uma das demandas dessa disciplina que os trabalhos fossem desenvolvidos em Linux.
